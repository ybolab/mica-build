# Decisions

One file per deliberate divergence from a `/pma` or stack-skill rule, named
`<YYYY-MM-DD>-<slug>.md`, each with the rule it relaxes, the reason, and a
sunset date. `AGENTS.md` links here and does not restate the rationale.

Recorded so far: none. Two known gaps are tracked as follow-ups in
`docs/plan/` rather than as divergences, because they are omissions and not
choices — the tree has no single aggregate quality-gate `make` target, and four
of its five `package.json` files declare no `engines`.
