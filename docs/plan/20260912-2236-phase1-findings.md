## Context

Seven pre-existing defects surfaced while proving Phase 1 of the package
repository split on 2026-09-12; the task record lists them with their
evidence. Each was worked around (builder set by hand, followers attested,
`public-meta` copied, failures reported) so the proof could finish. This plan
fixes them at their causes; nothing here changes the lock, the provenance
fields or the composer's two-class rule.

## Proposal

1. **BSP builder selection.** `boards/s905x5m/bsp/Makefile` (and the cx3576
   equivalent if it shares the shape) takes the same register as
   `build-env/deb/build.sh`: `BUILDX_BUILDER` wins; otherwise `default` when
   `docker buildx inspect default` lists `linux/arm64`, else the
   `mos-arm64` docker-container builder, created if absent. One helper in
   `build-env/` (`builder.sh --platform linux/arm64`) so the rule is written
   once and `build.sh`, `rootfs/build.sh` and the BSP Makefiles read it.
2. **Board package exclusivity.** Each `mos-board-*` control template
   declares unversioned `Conflicts:` with every other board package, both
   directions, so `deb-package-gate.sh`'s existing exemption ("exactly two
   packages, mutual unversioned Conflicts") licenses the shared layout files.
   The gate's exemption is per pair; with three boards the shared path is
   claimed three times, so the exemption is widened from "exactly two" to
   "every claimant conflicts with every other claimant", and the message
   still names the path and the packages.
3. **Native endpoint attribution.** `checks-file-root.ts` stops attesting the
   bytes that follow a diagnostic URL. A literal is attributed when the
   source string containing the URL precedes the match exactly and the
   literal's remainder past the URL does not begin with `/`, `?` or `#` (the
   three ways a URL is extended); the remainder is then the next merged
   string and carries no endpoint. The test that requires an unknown
   adjacent suffix to be refused is replaced by tests that a `/updates`,
   `?…` or `#…` extension is refused and that a merged neighbour is accepted.
   `NATIVE_DIAGNOSTICS` loses its `following` arrays.
4. **Public metadata default.** `rootfs/build.sh` derives the public subset
   from `MOS_META_DIR` (default `meta/`) into `_out/<board>/meta-public/`:
   `updates/manifest.json` and `GENERATED` when present, nothing else, and
   runs `validate-public-meta.sh` over the copy. A caller who already points
   `MOS_META_DIR` at a public directory gets the same result.
5. **pipefail lint.** The two findings become `grep -c … >/dev/null`, as the
   lint's message says.
6. **Factory-root gate negative case 5.** The device comparison's negative
   case plants a character device only when the export carries one; with a
   root that ships none by design, the case asserts that the export carries
   no device node at all and reports that as its evidence, instead of
   failing on an empty comparison.
7. **Gate records.** After 1 to 6, `make os-deb-package-gate` (with its
   rebuild), `make os-verify` on an x64 image and `make os-rootfs-x64` with
   no `MOS_META_DIR` are run on a clean checkout and recorded in
   `docs/changelog.md`.

## Verification

- `make os-deb-s905x5m-bluetooth` on this host (no binfmt) builds.
- `make os-deb-package-gate` green, including the reproducibility rebuild,
  over both pools with the three arm64 boards present.
- `bun test` in `verify/` green with the rewritten endpoint tests;
  `make os-verify` green on the x64 image of the same commit.
- `MOS_BOARD=x64 bash rootfs/build.sh` composes with `meta/` untouched.
- `bash tests/shell-pipefail-lint.sh` reports 0 findings.

## Risks

- Widening the ownership exemption to n-way mutual conflicts must not
  license an accidental overlap: the exemption still requires every claimant
  to name every other claimant, which only the board packages do.
- Dropping follower attestation weakens the endpoint check by design; the
  URL-extension refusal keeps the property that matters (no default update
  or fleet endpoint compiled in), and the source-string match keeps the
  attribution exact.

- `tests/factory-root-gate/gate.sh` and its inner script.

## Alternatives

- Register binfmt on the host instead of selecting a builder: rejected, the
  tree's rule is that builds need no host registration.
- Keep attesting followers per build: rejected, it fails on every rebuild
  whose merged-string order shifts and the attestation says nothing about
  endpoints.
