## Repair design

Await the existing bounded mosd call before returning 202, which acknowledges
admission rather than completed reboot. Return 409 `power_refused` for a policy
or permission refusal and preserve 500/503/504 backend failure classifications.
Audit failed dispatch. Close power confirmation on submission and expose the
existing success/error panel. Keep authentication, reboot interlocks and systemd
execution unchanged; do not add compatibility paths or automatic power retries.
A disconnect or timeout cannot establish whether the reboot completed.
