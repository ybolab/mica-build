## Description

Verify and repair the existing promise that a board booted without HDMI displays
its logo when a monitor is attached later. The pinned kernel's logo.c marks logo
data unavailable at late initialization, and pnmtologo.c emits init-only artwork.
Later fbdev creation alone therefore cannot guarantee a logo. Test the artwork
lifetime and actual board hotplug path before choosing the repair.
