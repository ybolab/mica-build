# RFCT-125 PLAN-015 M5: the two HARNESS files become manuals instead of campaign journals

- **status**: done
- **priority**: P2
- **owner**: PLAN-015 M5
- **createdAt**: 2026-08-26
- **plan**: PLAN-015 (M5)

`os/verify/HARNESS.md` is a register keyed to line numbers of a file that no
longer exists. `os/build/HARNESS.md` carries four byte-identity gate sections
for a migration that has finished.

Reduce both to manuals: what the harness is, how it is run, and what its output
means. The tool-behaviour measurements in them are kept and reworded to present
tense; the campaign record around them is deleted, not relocated.
