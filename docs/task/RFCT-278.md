## Description

Create the embedded-first, versioned user-documentation structure and official
website content contract without presenting proposed product work as shipped.

## Acceptance

- Customer navigation covers release selection through installation,
  operation, applications, update, recovery, troubleshooting and support.
- Website briefs cover product, downloads, hardware, docs, security and support.
- Every capability is labelled shipped, board-dependent, proposed or
  unsupported and is tied to evidence.
- English/Chinese version and coverage rules are visible and testable.
- Documentation checks cover navigation, internal links and selected examples.

## ActiveForm

Building the user documentation and website content contract.

- **blocks**: truthful publication of customer documentation and website copy
