# UI-001 Define the built-in UI development guide

- **status**: completed
- **priority**: P1
- **owner**: codex/ui-guide-20260901
- **createdAt**: 2026-09-01 21:06

## Description

Produce a self-contained Chinese development guide for the built-in UI, based
on the current implementation, `docs/research/venus-gui-v2.md`, and unfinished
roadmap plans. The guide must distinguish shipped contracts from draft planned
capabilities and be usable by a UI engineer without additional repository
archaeology.

## Acceptance

- The guide inventories current pages, routes, APIs, states, permissions, and
  device workflows from repository evidence.
- Planned capabilities are mapped to their owning tasks/plans and are visibly
  separated from shipped behavior.
- The proposed information architecture, page specifications, component and
  interaction conventions, responsive/accessibility requirements, and staged
  delivery order are explicit.
- A UI engineer can identify which screens may bind live APIs, which require
  placeholders or feature gates, and which remain out of scope.
- The final Chinese handoff is self-contained and links back to repository
  contracts only for traceability, not for essential understanding.
