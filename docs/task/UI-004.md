# UI-004 Add localization and selectable Spectrum themes

- **status**: completed
- **priority**: P1
- **owner**: codex/i18n-theme-20260901
- **createdAt**: 2026-09-01 22:10

## Description

Add complete English and Simplified Chinese localization to the shipped
built-in SPA, plus user-selectable light, dark and system color themes. The
choice must persist locally, work before and after authentication, respect the
fixed embedded-asset contract, and preserve current device behavior. UI
components must remain shadcn `base-nova` primitives backed by Base UI, with
Adobe Spectrum 2 mapped into the visual, state, theme and accessibility layer.

## Acceptance

- English and Simplified Chinese cover every frontend-owned visible string,
  accessible name, confirmation, fallback, date and uptime presentation in all
  shipped routes; backend evidence and unknown device values remain verbatim.
- Locale detection prefers the stored choice, then browser languages, then
  English; it persists safely and synchronizes the root language and title.
- Appearance supports persisted system/light/dark choices, tracks operating-
  system changes only in system mode, and synchronizes the root class,
  `color-scheme` and browser theme color.
- Preferences remain reachable before and after authentication, are keyboard
  accessible and use shadcn `base-nova` Selects backed by Base UI.
- Spectrum 2 roles are mapped to local semantic tokens for both color themes;
  action/focus/status roles are distinct and changed UI contrast meets WCAG
  2.2 AA without introducing an Adobe or other component runtime.
- Tests cover locale normalization/resource parity, preference persistence,
  document synchronization and system-theme changes; lint, typecheck, full
  tests, coverage, deterministic build and the APID UI gate pass.
- Production output remains exactly `index.html`, `assets/app.js` and
  `assets/app.css`, and the Chinese design/development guides match delivery.
