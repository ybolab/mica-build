# UI-005 Embed isolated UI asset trees

- **status**: completed
- **priority**: P1
- **owner**: codex/ui-vfs-20260901
- **createdAt**: 2026-09-01 23:10

## Description

Replace the built-in UI's fixed three-file embedding contract with a
compile-time embedded virtual asset tree that supports hashed chunks and lazy
loading. Keep request ownership limited to the three route namespaces `/`,
`/ui` and `/api`: root serves only the active local/custom UI, `/ui` serves
only built-in assets, and `/api` serves only the API. Neither routing nor asset
resolution may traverse, fall through or otherwise cross between namespaces.

## Acceptance

- The router has exactly three ownership domains: `/`, `/ui` and `/api`, with
  segment-aware reserved-prefix matching and deterministic precedence.
- Built-in UI output is embedded recursively as a compile-time virtual file
  tree rather than a fixed list of filenames.
- Each UI resolver receives only a prefix-stripped logical path and rejects
  traversal, encoded separators, backslashes, control bytes and other attempts
  to escape its assigned resource tree.
- `/api` requests and misses never fall through to either UI; built-in UI
  requests never fall through to root/custom UI; root/custom UI requests never
  access built-in assets.
- Vite emits deterministic hashed chunks with route and locale lazy loading,
  while direct SPA navigation remains correct within its owning UI tree.
- Rust routing/security tests and frontend quality/build gates cover namespace
  isolation, misses, navigation fallback and multi-file embedded delivery.
