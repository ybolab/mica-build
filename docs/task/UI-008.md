  dense responsive cards and tables, mobile navigation, Barlow typography and
  Spectrum-aligned light/dark tokens with shadcn base-nova controls on Base UI.

  unavailable product capabilities use only deterministic in-memory state.

  labeled in both supported locales.

  locale choices persist, and desktop/tablet/mobile visual baselines are
  committed for light and dark appearances.
- Lint, TypeScript 7 typecheck, 29 unit tests with enforced 80% coverage, 14
  applicable Playwright checks, the reproducible UI package gate and focused
  APID embedded-VFS/namespace tests pass.
