# UI-009 Generate built-in UI assets during the build

- **status**: completed
- **priority**: P1
- **owner**: ui-build/session-20260902
- **createdAt**: 2026-09-02 11:55

## Description

Stop source-controlling `pkgs/mosd/apid/ui/dist`. Make the frontend build an
explicit prerequisite of APID compilation and packaging, pass the generated
asset directory into the Rust build, and keep the complete generated tree
embedded in the APID binary.

## ActiveForm

Generated built-in UI assets during the build.

## Acceptance

- `pkgs/mosd/apid/ui/dist/` is ignored and contains no tracked files.
- The frontend quality gate produces a fresh production tree without comparing
  it to a repository copy.
- Local Rust checks and both APID cross-build paths build the frontend first and
  pass its absolute output path to `apid/build.rs`.
- `apid/build.rs` rejects a missing or unsafe generated tree and embeds every
  file from the supplied directory without depending on source-controlled
  output.
- Build and UI documentation describe the generated-asset contract.
