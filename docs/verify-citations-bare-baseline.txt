# Per-document ceilings for BARE CONTINUATIONS THAT RESOLVE AGAINST NOTHING,
# read by docs/verify-citations.sh (PLAN-028 M2, RFCT-257).
#
# A bare continuation is `:NNN`. It inherits the nearest citation or path
# earlier on its own line and is then checked in full. Where its line offers
# nothing to inherit from it is a counted skip and not an error -- PLAN-028's
# "unresolvable inheritance are ERRORS" was withdrawn by dated correction,
# because only a minority of the measured sites are document defects and the
# rest are correct as written: a form quoted rather than used, a port, a
# shorthand whose file is named in a table header, a frozen audit whose
# numbers ARE the measurement.
#
# The strictness the error arm was wanted for lives here instead. Format:
# <document> <ceiling>. A scanned document whose count EXCEEDS its row fails
# the run; a document with no row has a ceiling of 0, so a new document starts
# with none. The counts below are the corpus as measured when the resolver
# landed. Update procedure, and the only permitted direction is down: when a
# document's count drops -- a continuation given a path, a paragraph rewritten
# -- lower its row, or delete it at zero, in the SAME commit. Raising a row is
# possible and is meant to be conspicuous: it says a new unresolvable
# continuation was deliberately written, and the diff carries the decision.
# Dated records are exempt exactly as they are from the checks themselves.
