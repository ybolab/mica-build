# docs/verify-citations.sh (PLAN-020 class 1, the RFCT-173 ratchet).

# EXCEEDS its row fails the run; a document with no row has a ceiling of 0.
# Update procedure: when a document's unquoted count drops, lower its row --
# or delete it at zero -- in the same commit; when a new unquoted citation is
# genuinely wanted, raise the row in the same commit so the diff shows the
# decision. Ceilings are the measured counts, exact, not slack.
