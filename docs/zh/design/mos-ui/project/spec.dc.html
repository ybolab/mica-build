1 · 色彩

克莱因蓝（IKB）按其本来用法：大面积平涂 + 白字反白，只出现在顶栏、主按钮、当前项。内容区是暖调画廊白，与蓝形成冷暖对比；中性色统一带蓝调。

2 · 状态语义

颜色是信号。正常状态一律中性——运行中、链路正常、健康、已挂载不着色；出现颜色即需要注意。每个状态必带文字，不依赖颜色。

5 · 触控与尺寸

44px触屏（pointer:coarse）下按钮、输入框、导航项、菜单项最小高度；抽屉项 48px
1 / 1.5 px卡片 1px；输入框与次级按钮 1.5px。操作按钮行不加顶部分隔线
6 / 8 px控件 6px、卡片 8px 圆角；标签 4px 方角，不做胶囊
  • 按压反馈：缩放 0.97 + 底色变深；触摸 8ms 震动，主操作 / 危险操作 18ms；尊重 reduced-motion。
  • 移动端输入框 16px 防止 iOS 缩放；底部留 safe-area。
  • 焦点环 2px 强调色，不用浏览器默认。

6 · 组件约定

  • 密钥 / PIN 类展示：等宽大号 + 连体「复制」按钮组，同一边框内竖线分隔；轮换 / 关闭等动作在同行右侧垂直居中。
  • 上传类流程：上传 → 校验签名 → 暂存（显示摘要与签名者）→ 安装 / 使用。UI 包、更新包、配置备份同一套。
  • 终端窗口：深色固定配色（不随主题），右上 最小化 / 全屏 / 关闭；最小化为右下悬浮条，会话保留；点遮罩为最小化。
  • 语言：设置菜单只显示当前语言名（地球图标）；选择走带搜索的列表对话框，含「自动 · 跟随浏览器」；未翻译语言标「计划中」并回退英文。
  • 主题：浅 / 深 / 自动三段，自动跟随系统。
